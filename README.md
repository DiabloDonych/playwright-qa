# Playwright QA Practice

Учебный проект по автоматизации веб-приложений с использованием:

- Python
- Playwright
- Pytest
- Allure

## Tests

На данный момент тесты проверяют:

- открытие сайта;
- переход на страницу товара;
- название товара;
- цену;
- состояние кнопки Add to Cart;
- добавление товара в корзину;
- поиск товара;
- URL страниц.
